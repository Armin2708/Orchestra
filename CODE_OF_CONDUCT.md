# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful and constructive; harassment, personal attacks,
and discriminatory behavior are not tolerated in issues, PRs, discussions, or
any other project space.

Reports: **radarmine1@gmail.com** (handled confidentially). The maintainer
may warn, moderate, or ban accounts that violate this standard.
