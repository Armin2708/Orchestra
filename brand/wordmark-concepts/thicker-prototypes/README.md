# Orchestra mark weight prototypes

These studies preserve the approved 21-seat, 9–7–5 arrangement. Only the
outward visual weight of each existing shape changes.

| Prototype | Added edge weight | Approx. seat width | Intent |
| --- | ---: | ---: | --- |
| A — Current | 0 | 24 units | Production reference |
| B — Medium | 1 unit per edge | 26 units | Subtle reinforcement |
| C — Bold | 2 units per edge | 28 units | Stronger default candidate |
| D — Extra bold | 3 units per edge | 30 units | Maximum useful weight |

`weight-comparison.svg` and `weight-comparison.png` show all four directions
at display and small-icon sizes. The canonical assets in `brand/identity/`
remain unchanged until a direction is selected.
