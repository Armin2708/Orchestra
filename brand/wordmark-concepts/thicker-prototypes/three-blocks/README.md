# Three-block section prototypes

Each prototype reduces the mark to three blocks per grayscale row. Width grows
from the outer row to the middle row to the inner row while the formation stays
bilaterally balanced around the centered podium.

| Prototype | Outer width | Middle width | Inner width |
| --- | ---: | ---: | ---: |
| A — Gentle | 30 | 42 | 56 |
| B — Balanced | 36 | 52 | 68 |
| C — Strong | 40 | 60 | 82 |

These are concept studies only. Production assets remain unchanged.
