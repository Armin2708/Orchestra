# Orchestra identity

The Orchestra mark is a top-down ensemble: exactly 21 angular seats in 9–7–5 semicircular rows, facing one centered horizontal podium. The formation is the identity; do not redraw it as sound waves, a network, a letter, or a literal instrument.

## Production assets

| Asset | Use |
| --- | --- |
| `orchestra-mark.svg` | Primary mark on light or transparent surfaces |
| `orchestra-mark-reversed.svg` | Primary mark on dark surfaces |
| `orchestra-app-icon.svg` | Square app icon master on warm white |
| `orchestra-app-icon-dark.svg` | Browser favicon master on black |

Use the mark with the lowercase word `orchestra` set in Geist or the product's system sans at 600 weight. The wordmark is live type so it remains crisp, accessible, and consistent with the interface.

## Rules

- Preserve all 21 seats and their 9–7–5 row count.
- Preserve the three flat colors: `#A1A19B`, `#62625D`, and `#111111`.
- Keep the podium horizontal, centered, square-cornered, and the same width as the production master.
- Use the reversed asset on surfaces darker than `#62625D`; never place the default black podium on a dark surface.
- Keep clear space around the mark equal to one inner-row seat height.
- At 24 px and below, use the symbol alone. Do not add detail, shadows, outlines, gradients, or animation.
- Do not round the seats or podium, alter the row count, rotate the mark, recolor individual seats, or place text inside the icon.
